# STATUS SEAT PLAN A340 · ตรวจสภาพที่นั่งและ Monitor

หน้าเว็บให้ฝ่ายการช่าง/ฝ่ายสื่อสารบันทึกสภาพที่นั่งและ Monitor ของเครื่อง A340 (165 ที่นั่ง, Monitor 48 จอ)
รวมถึง Galley 45 รายการ และห้องน้ำ 11 ห้อง
ข้อมูลทุกครั้งที่กด **SAVE** จะบันทึกลง Google Sheet **Seat Plan 340 (For Admin)** โดยตรง
และเพิ่มบรรทัดในแท็บ **ประวัติการแก้ไข**

## การเข้าใช้งาน: ระบบ Login กลาง ฝูง.602 (ตั้งแต่ 12 พ.ย. 2026)
- ไม่มีรหัส (`WRITE_PIN`, `ADMIN_PIN`) และไม่ต้องพิมพ์ชื่อผู้ตรวจแล้ว เปิดหน้าเว็บแล้วระบบพาไปหน้าเข้าสู่ระบบกลาง ([repo eadmin](https://github.com/rtaf602/eadmin)) แล้วพากลับมา
- Admin หลักกำหนดในหน้า Admin ส่วน "สิทธิ์เข้าใช้งานเว็บ" (รหัสเว็บ `WEB2`) ว่าใครเป็น Role อะไร
  - **Admin**: ดู แก้ไข SAVE ส่งออก และ "ล้างข้อมูลทั้งหมดเพื่อเริ่มรอบตรวจใหม่"
  - **Editor**: ดู แก้ไข SAVE ส่งออก PDF / Excel
  - **Viewer**: ดูและส่งออก PDF (ทั้ง 2 แบบ) / Excel ได้ ไม่มี SAVE, CLEAR และ PREVIEW
  - ไม่มีสิทธิ์: เข้าไม่ได้
- ชื่อผู้ตรวจ = ชื่อ-สกุลของบัญชีที่ Login (จากชีท LOGIN DATABASE ของระบบ Login) ใช้ในประวัติการแก้ไข SAVE ล่าสุด และไฟล์ที่ส่งออก
- EXPORT TO PDF ALL PAGES / EXPORT PDF SUMMARY 4 PAGES / EXPORT TO EXCEL บันทึกในแท็บ **ประวัติการส่งออก** (แยกจากประวัติการแก้ไข สร้างเองครั้งแรกที่มีการส่งออก): เวลา, ชื่อ-สกุล, Username, Role, ชนิดไฟล์, ชื่อไฟล์
- ทุกคำขอ Apps Script ถามระบบ Login (การ SAVE ถามทุกครั้ง การดึงข้อมูลถามซ้ำทุก 1 นาที)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (ผังที่นั่ง Galley ห้องน้ำ, ปุ่ม CLEAR / PREVIEW / SAVE / EXPORT TO PDF ALL PAGES / EXPORT PDF SUMMARY 4 PAGES / EXPORT TO EXCEL) |
| `export-excel.js` | สร้างไฟล์ EXPORT TO EXCEL 4 แผ่นงาน: ผังที่นั่ง, รวมข้อขัดข้องคงค้าง, ทุกที่นั่ง และ Monitor, ประวัติการแก้ไข |
| `config.js` | ใส่ URL ของ Apps Script Web App |
| `apps-script/Setup-Galley-Map.gs` | ใช้ครั้งเดียว: วาด Galley และห้องน้ำลงในแท็บ "ผังที่นั่ง" (ดูวิธีใช้ในหัวไฟล์) |
| `apps-script/Code.gs` | โค้ดที่วางใน Apps Script ของ Google Sheet: อ่าน/บันทึกข้อมูลให้หน้าเว็บ และเก็บประวัติเมื่อแก้ในชีทโดยตรง |

## การติดตั้ง (ทำครั้งเดียว)

### 1. เปิดหน้าเว็บด้วย GitHub Pages
1. ใน repo นี้ ไปที่ **Settings > Pages**
2. Source เลือก **Deploy from a branch**, Branch เลือก **main** และ **/ (root)** แล้วกด Save
3. รอ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://rtaf602.github.io/a340_seatplan/`

### 2. ติดตั้ง Apps Script ใน Google Sheet
1. เปิด Google Sheet **Seat Plan 340 (For Admin)** > **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดเดิมทั้งหมดใน `Code.gs` แล้ววางโค้ดจาก `apps-script/Code.gs` (โค้ดนี้รวมการเก็บประวัติเดิมไว้แล้ว)
3. ในบรรทัด `const LOGIN = { LOGIN_URL: '', ... }` ใส่ `LOGIN_URL` เป็นที่อยู่ระบบหลังบ้านของระบบ Login (ค่า `backendUrl` ในไฟล์ `docs/assets/config.js` ของ repo eadmin)
   และตรวจว่า `WEB_CODE` ตรงกับรหัสเว็บในรายชื่อเว็บของหน้า Admin และตรงกับ `webCode` ในไฟล์ `config.js`
4. กด **บันทึก (Save)** เลือกฟังก์ชัน **setup** แล้วกด **Run** (อนุญาตสิทธิ์ "เชื่อมต่อบริการภายนอก") Execution log ต้องขึ้น "ระบบ Login ตอบแล้ว" และ "ตั้งค่าเสร็จแล้ว"
5. กด **Deploy > New deployment** > ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. กด **Deploy** แล้วกดอนุญาตสิทธิ์ (Authorize access) ด้วยบัญชีเจ้าของชีท
7. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 3. เชื่อมหน้าเว็บกับชีท
แก้ไฟล์ `config.js` ใน GitHub ใส่ URL จากข้อ 2.7:

```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

กด Commit แล้วรีเฟรชหน้าเว็บ แถบด้านบนจะขึ้น "ข้อมูลจาก Google Sheet"

## เมื่อแก้โค้ด Apps Script ภายหลัง
กด **Deploy > Manage deployments >** ไอคอนดินสอ > Version เลือก **New version** > Deploy
URL เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`

## การทำงาน
- หน้าเว็บโหลดผังจากแท็บ "ผังที่นั่ง" และดึงข้อมูลใหม่ทุก 30 วินาที
- SAVE: เขียนสภาพที่นั่ง, Monitor และหมายเหตุลงช่องในชีท และเพิ่มประวัติ (ช่องอีเมลจะเป็น "หน้าเว็บ" และช่องผู้ตรวจเป็นชื่อ-สกุลของบัญชีที่ Login)
- กรอกพร้อมกันหลายคน: SAVE จะเขียนเฉพาะช่องที่คนนั้นแก้จริง ถ้าแก้ที่นั่งเดียวกันคนละช่อง (เช่น คนหนึ่งแก้เก้าอี้ อีกคนแก้จอ) ค่าของทั้งสองคนจะอยู่ครบ ถ้าแก้ช่องเดียวกันและมีคน SAVE ไปก่อน หน้าเว็บจะไม่บันทึกทับ แต่ถามคนที่ SAVE ทีหลังว่าจะใช้ค่าที่บันทึกไว้หรือค่าของตัวเอง
- Galley และห้องน้ำเก็บในแท็บ "Galley และห้องน้ำ" (สร้างเองครั้งแรกที่หน้าเว็บโหลดข้อมูลหลังติดตั้ง Apps Script รุ่นนี้ พร้อมค่าเริ่มต้นในชื่อ ร.อ.ธัญชนิต จินตภากร) แก้คอลัมน์ สภาพ/หมายเหตุ ในชีทโดยตรงก็บันทึกประวัติ
- แก้ในชีทโดยตรงก็บันทึกประวัติเช่นกัน และหน้าเว็บจะเห็นค่าใหม่ในรอบดึงข้อมูลถัดไป
- ถ้ายังไม่ได้ใส่ `API_URL` หน้าเว็บยังเปิดดูและแก้ได้ แต่ SAVE ไม่ได้

## ข้อควรรู้ด้านความปลอดภัย
- Web App ตั้งเป็น "Anyone" แต่ทุกคำขอต้องมีบัตรผ่านจากระบบ Login กลาง ไม่มีบัตรผ่าน Apps Script ไม่อ่านและไม่เขียนอะไรเลย
- หน้าเว็บไม่ส่งการ Login ตัวจริงให้ Apps Script ของเว็บนี้ ส่งแค่บัตรผ่านที่ใช้ได้กับเว็บนี้เท่านั้น
- Repo นี้เป็น public ห้ามใส่รหัสผ่านลงในไฟล์ใดใน repo
- ประวัติการแก้ไขอยู่ในชีท ผู้มีสิทธิ์แก้ไขชีทลบได้ ควรล็อกแท็บ "ประวัติการแก้ไข" ด้วย Protect sheet ให้เฉพาะ Admin
